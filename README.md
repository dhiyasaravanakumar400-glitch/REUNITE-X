# REUNITE-X – Disaster-Affected Family Reunification Platform

## Problem Statement

During natural disasters such as floods, cyclones, earthquakes, and landslides, families may become separated during evacuation, rescue operations, and relocation to relief camps.

Information about missing people is often scattered across hospitals, police stations, rescue teams, NGOs, and relief camps. Families face difficulties finding their loved ones because there is no centralized system connecting these records.

## Proposed Solution

REUNITE-X is a disaster family reunification platform that helps families register, report missing people, and search for available family records.

The system provides a unique Family ID, missing-person reporting, case ID generation, and search functionality. It aims to help authorities connect related records and verify potential matches.

## Key Features

- Family Registration
- Unique Family ID
- Report a Missing Person
- Find a Missing Person
- Search by Person Name or Family ID
- Missing Report Case ID Generation
- AI-Assisted Toll-Free Helpline (Proposed)
- Identity Verification
- Disaster Case Management

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: H2 Database
- Data Access: Spring Data JPA
- Build Tool: Maven
